# Example Project

## What This Is
This is an example project file that will be picked up by the YouTube Story Builder.

## Description
The YouTube Story Builder reads all files in this `projects/` directory to source content for your daily stories. You can:

- Add markdown files with project descriptions
- Add JSON files with structured project data
- Reference your accomplishments, challenges, and lessons learned
- Update these files as your projects evolve

## How It Works
1. The system reads all .md and .json files in this folder daily
2. Combines this content with your recent emails
3. Claude AI creates a compelling narrative
4. Story is saved to your Google Drive

## Tips
- Keep descriptions concise but rich in detail
- Include challenges and how you overcame them
- Mention metrics or results when possible
- Update regularly with new projects
- Use these to tell authentic stories
