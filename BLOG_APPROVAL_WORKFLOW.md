# Blog Post Approval Workflow

**Purpose:** Ensure all blog content meets quality standards before publishing  
**Created:** 2026-06-24

---

## Approval Process Overview

```
STEP 1          STEP 2           STEP 3          STEP 4
Writer writes → Submit draft → Review/Approve → Publish to site
blog post         for review      & feedback       (live)
                                                    
              (Optional: Multiple rounds of revision)
```

---

## Step 1: Blog Post Creation

### Writer Responsibilities
- Write compelling, informative content (500-1500 words)
- Target keywords for SEO optimization
- Include relevant internal links
- Add a clear headline and meta description
- Use proper formatting (headings, bullets, etc.)

### Required Information for Each Post
```
Title: [Main headline]
Meta Description: [160 characters describing the post]
Category: [Helical Piers / Foundation Repair / Installation / General]
Tags: [3-5 relevant tags]
Author: [Your name]
Target Keywords: [Primary keyword, secondary keywords]
Read Time: [Estimated minutes]

Content:
- Headline (H1)
- Introduction (100-150 words)
- Main sections with subheadings (H2/H3)
- Bullet points or numbered lists
- Call-to-action
- Conclusion

SEO Elements:
- Keyword density checked
- Internal links added (2-3 relevant links)
- External authority links (1-2 if applicable)
- Image alt text included
```

## Step 3: Review & Approval

### Review Criteria

**Content Quality:**
- [ ] Information is accurate and factual
- [ ] Writing is clear and professional
- [ ] No grammar/spelling errors
- [ ] Flows well and is easy to read
- [ ] Provides real value to readers

**SEO Optimization:**
- [ ] Target keyword appears in title
- [ ] Meta description is compelling (< 160 chars)
- [ ] Keyword density is appropriate (not over-optimized)
- [ ] Internal links are relevant
- [ ] Headings use proper hierarchy (H1, H2, H3)
- [ ] Image alt text is descriptive

**Business Alignment:**
- [ ] Aligns with brand voice/messaging
- [ ] Promotes services appropriately (not overly sales-y)
- [ ] Contains call-to-action
- [ ] No conflicting information

**Technical:**
- [ ] Proper formatting for web
- [ ] Images optimized for loading speed
- [ ] Links work correctly
- [ ] No broken links

### Feedback Categories

**✅ APPROVED**
- Post is ready to publish as-is
- No changes needed

**✅ APPROVED WITH MINOR EDITS**
- Post is good; I'll make small tweaks (grammar, formatting, etc.)
- No major revisions needed

**🔄 REQUEST REVISIONS**
- Content needs revision before publishing
- Specific feedback provided
- Resubmit for re-review

**❌ REJECTED**
- Post doesn't meet standards
- Requires significant rework or alternative approach

### Feedback Response

**Feedback Format:**
```
Post Title: [Title]
Status: [APPROVED / APPROVED WITH MINOR EDITS / REQUEST REVISIONS / REJECTED]

Strengths:
- What the post does well

Feedback:
- Specific suggestions for improvement
- Questions about accuracy
- SEO optimization tips

Action Items:
1. [Specific revision request]
2. [Specific revision request]
3. [etc.]

Approved to Publish: [Yes/No]
Target Publish Date: [Date if approved]
```

## Step 4: Publish to Website

### Publishing Checklist

Once approved:
- [ ] Copy content to HTML/CMS
- [ ] Add featured image (if applicable)
- [ ] Set publish date & time
- [ ] Configure SEO metadata
- [ ] Set category & tags
- [ ] Preview on website
- [ ] Test all links work
- [ ] Test on mobile device
- [ ] Publish!

### Post-Publish

- [ ] Share on social media (Facebook, LinkedIn, etc.)
- [ ] Send email to subscribers (optional)
- [ ] Monitor comments
- [ ] Track analytics (visitors, time on page, shares)

## Quality Standards Checklist

Before submitting, make sure:

**Writing Quality:**
- [ ] No spelling or grammar errors
- [ ] Consistent tone and voice
- [ ] Paragraph length is reasonable (2-4 sentences max)
- [ ] Clear topic sentences
- [ ] Logical flow

**Content Accuracy:**
- [ ] All facts are verified
- [ ] Statistics have sources
- [ ] No outdated information
- [ ] Links to reputable sources
- [ ] No contradictions with previous posts

**SEO Optimization:**
- [ ] Target keyword in title
- [ ] Target keyword in first paragraph
- [ ] Meta description is under 160 characters
- [ ] Internal links (2-3) to other pages/posts
- [ ] Subheadings use H2/H3 tags
- [ ] Image alt text describes image

**User Experience:**
- [ ] Scannable (bullets, headings, short paragraphs)
- [ ] Visual breaks (not wall of text)
- [ ] Clear call-to-action
- [ ] Valuable to reader
- [ ] Answers the question in the title

**Professionalism:**
- [ ] Professional tone
- [ ] Aligned with brand voice
- [ ] No personal opinions presented as facts
- [ ] Balanced and fair
- [ ] Credible and authoritative

## FAQ

**Q: How often should I submit blog posts?**  
A: Target 2-3 posts per month for best SEO results. But quality over quantity!

**Q: Can I write about topics not on the approved list?**  
A: Yes! Just get pre-approval before writing to avoid wasted effort.

**Q: How long does approval take?**  
A: Usually 2-3 business days for initial review. Revisions within 3-5 days.

**Q: Can I see approved posts before publishing?**  
A: Yes! You'll get a preview link to review the final published version.

**Q: What if I disagree with feedback?**  
A: Let's discuss! Feedback is collaborative. The goal is content we're both proud of.
