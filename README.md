# Rant

## Projects

This repository contains two separate projects:

### 1. Static Website (Root)
- **Texas Rigs & Roots** - Professional service website
- Files: `index.html`, `style.css`, `main.js`, `funnel-bammel/`
- Deployed on Netlify
- Landing page and lead generation for home repair services

### 2. YouTube Story Builder (Backend)
- **Automated Story Generation** - Daily YouTube content automation
- Location: `youtube-story-builder/`
- Node.js application with Claude AI integration
- Pulls from Gmail + local projects, generates stories
- Saves to Google Drive daily
- See `youtube-story-builder/README.md` for setup

## Getting Started

**To run the website locally:**
```bash
# Just open index.html in a browser or serve with any HTTP server
```

**To set up YouTube Story Builder:**
```bash
cd youtube-story-builder
npm install
npm run setup
npm start
```

See the respective README files for detailed documentation.
